# Louise Nguyen — Editorial Portfolio

A static HTML/CSS/JavaScript portfolio designed for GitHub Pages.

## Replace these first

1. Add your homepage photo as `assets/hero-photo.jpg`.
2. Add your resume as `assets/Louise-Nguyen-Resume.pdf`.
3. Replace `your-email@example.com` in `index.html`.
4. Replace the placeholder collage blocks with your own images and project links.
5. Edit the "currently" note so it stays personal and current.

## Publish through GitHub Pages

1. Create a public repository named `YOUR-USERNAME.github.io`.
2. Upload everything inside this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Your site will appear at `https://YOUR-USERNAME.github.io`.

## Local preview

Open `index.html` directly in your browser, or run a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
